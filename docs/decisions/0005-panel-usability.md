# 0005 — 面板可用性：渐进分页、排序与可访问性

- 状态：已采纳（2026-11-13）
- 影响范围：`src/client/index.js`、`src/client/styles.module.css`、`lib/client.js`、`docs/feature-matrix.md`、`docs/architecture.md`

## 背景

面板在一次 `/session-kit/list` 中拿到完整的会话目录（workspaces + sessions），
在客户端按工作区分组、搜索、筛选、选择。数据量增大后，一次性渲染所有分组和行
会变慢，滚动也失去定位；同时 P3/P4/P5 新增的多选工作区、迁移对话框和回收站卡片
让交互变复杂，需要更明确的选择集反馈与键盘可达性。

原 P6 计划写了「虚拟滚动/分页、服务端搜索与排序、选择集语义、i18n、主题 token、
对话框可访问性」。逐项评估后：

- **服务端搜索/排序**：`/list` 的返回是分组与「跨分组选择」的唯一事实来源；把过滤
  放到服务端会让选择集、分组计数、跨页全选都要重新定义，且每次输入都要请求。
  当前实现规模（几百到几千会话）下，客户端过滤是即时的，也更不容易出现选择漂移。
- **虚拟滚动**：真正的 windowing 需要测量行高、处理详情展开/折叠和粘性分组头，
  在没有浏览器自动化测试的前提下收益小于回归风险。
- **渐进分页**：用很小的改动就能显著减少首屏 DOM 数量，且保留分组语义。

## 决策

### 1. 渐进分页（每组独立窗口）

- 每组初始最多渲染 `GROUP_PAGE_SIZE = 25` 行；
- 列表底部出现「显示更多（已显示 X/Y）」按钮，每次把每组窗口增加 25；
- 搜索词、状态筛选或排序变化时窗口重置为 25；
- 分组标题仍显示该组**过滤后的完整数量**，不是已渲染数量；
- 行选择、详情展开、归档/删除/迁移等操作仍按完整会话对象工作，未渲染的行
  不影响它们。

### 2. 排序

搜索框右侧新增排序选择器，四个键：

| 值 | 含义 | 次级排序 |
| --- | --- | --- |
| `recent`（默认） | 最近更新 | 创建时间/最近键 |
| `created` | 创建时间新→旧 | 最近更新 |
| `title` | 标题（`localeCompare`） | 最近更新 |
| `path` | 工作目录（`localeCompare`） | 最近更新 |

排序只改变组内会话顺序，不改变工作区分组顺序。允许值由 `SESSION_SORTS` 白名单
约束；未知值回退 `recent`。

### 3. 选择集语义

- 组头复选框仍然选择/取消该组**全部过滤后会话**（含尚未渲染的行）；
- 选中但不在当前搜索/筛选结果中的数量显示为「其中 N 个不在当前筛选结果中」；
- 顶部「全选」作用于当前过滤后的全部结果（不是当前已渲染窗口）；
- 刷新目录时仍按现有逻辑剔除已不存在的会话 id。

这与 P5/P4 的批量操作一致：批量请求拿到的是 id 列表，与渲染窗口无关。

### 4. 对话框可访问性

- 保留 `role="dialog"`、`aria-modal="true"`、`aria-label` 与 `autoFocus` 取消按钮；
- `Escape` 关闭（忙碌时忽略）；
- `Tab`/`Shift+Tab` 在对话框内循环（`trapDialogFocus`），不会把焦点移回背景页；
- 所有按钮/输入/下拉新增统一 `:focus-visible` 轮廓（`--dsw-focus-ring-color`）。

### 5. 主题 token 与 i18n

- 新增样式只使用 `--dsw-*` 主题变量（文字/边框/焦点环），并提供保守回退值；
- 新增文案全部进入内联 `zh`/`en` 字典并保持 key 对等：
  `panel.sortBy`、`panel.sortRecent`、`panel.sortCreated`、`panel.sortTitle`、
  `panel.sortPath`、`panel.loadMoreSessions`、`panel.shownSessions`、
  `panel.selectedHidden`。

## 明确不做

- 不引入服务端 `q` / `sort` / `limit` 参数；`/list` 契约不变。
- 不做 DOM 虚拟滚动；当单次目录超过约 2000 个会话、渐进分页仍不足时再评估。
- 不改变 `/list` 返回结构、分组规则或选择集的 id 语义。

## 后果

- 首屏渲染行数从「全部」降为「每组 25」，滚动更稳定；用户需要多点一次才能看到
  长尾会话。
- 分组计数与「已显示」可能不同，这是有意为之（计数表示筛选结果，窗口只影响渲染）。
- 排序是本地行为，不持久化；刷新页面回到 `recent`。
- 键盘用户可以在对话框内完成确认/取消，不会误触背景按钮。
- 没有新增自动化测试（客户端无 DOM 测试环境），回归依赖 `test/client-build.test.mjs`
  的构建契约与手工面板回归；文档在 `docs/feature-matrix.md` F16 记录这一点。

## 验证

- `npm run build:client` 产物包含新文案与 `trapDialogFocus`；`client-build` 测试通过。
- `npm test` 300 tests / 291 pass / 9 skip。
- 手工回归项：>25 行的分组出现「显示更多」；切换搜索/筛选/排序后窗口重置；
  选中未渲染行后顶栏出现隐藏计数；组头全选包含未渲染行；对话框 Tab 循环与
  Escape 关闭；焦点轮廓可见。

## 回滚

删除 `GROUP_PAGE_SIZE` / `groupLimit` / `shownGroups` 与底部按钮、移除排序选择器、
恢复 `buildGroups` 的三参数签名，并移除对话框的 Tab 陷阱与新增 CSS 即可；
`/list` 与选择集契约未改动，回滚不影响 Host 数据。
