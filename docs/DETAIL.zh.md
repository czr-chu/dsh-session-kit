# DeepSeek Harness 会话管理

dsh-session-kit 为 DeepSeek Harness 增加 **会话管理** 面板和 `session_kit`
agent 工具，用来在机器之间迁移会话、保留可用的本地备份，并在不手工修改
DSH 存储格式的前提下管理会话。

## 主要功能

- 按工作区浏览会话，按标题、id、目录搜索，筛选活跃/已归档；展开行可看存储大小、
  格式状态、归档状态和推导出的相关文件列表。
- 选择一个或多个会话导出为一个 ZIP。**精简** 保留可见对话与每轮最终回答；
  **全量** 保留完整事件日志和附件；可选打包整棵工作区树（排除敏感与构建目录）。
- 导入时只新建会话，可选恢复工作区文件，绝不覆盖已有会话。
- 归档/恢复；删除到 `$DSH_HOME/session-kit-trash`；或经独立确认后永久删除。
- 通过 DSH 官方迁移链升级旧日志；旧代际保留，官方拒绝时如实报告。
- 把 `chat.deepseek.com/share/<id>` 公开分享对话导入到选定工作区的新会话。

## 安全提示

- 相关文件处理是实验性、尽力推导：shell 重定向、脚本产物、正文提到的文件无法发现，
  共享文件可能受影响。界面要求显式勾选文件并二次确认。
- 永久删除不进回收站、不可回滚。
- 导出包含对话内容，也可能包含工作区文件；分享前请检查。不要提交会话数据或凭据。
- 工作区导出会排除 VCS 元数据、依赖/构建缓存、符号链接和凭据类文件，但不能替代安全审查。

## 安装

```sh
dsh plugin --profile web add github:czr-chu/dsh-session-kit#v0.10.5
```

安装或升级后重启 `dsh web`。插件不依赖任何 `@deepseek-ai/*` 运行时包，
通过 composed service registry 读取 DSH 能力。
